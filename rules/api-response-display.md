# API 응답 표시

API 요청을 보내고 그 응답을 사용자에게 보여줄 때의 규칙.

## JSON 응답은 pretty print 그대로

단건 조회나 일반적인 응답은 JSON을 **pretty print 형식으로 그대로** 보여준다. 임의로 요약·재구성하지 않는다.

```bash
curl -s "$URL" | python3 -m json.tool --no-ensure-ascii
```

## 큰 응답(목록 등)은 관심 컬럼만 표로

목록 조회처럼 응답 내용이 클 때는, 그 때의 관심사에 해당하는 필드만 골라 **표 형태**로 요약해서 보여준다.

- 전체 JSON 전문은 사용자가 **특별히 요청한 경우에만** 보여준다 ("json 보여줘" 등).
- 표로 요약했더라도 요청이 오면 즉시 pretty print 전문을 제공한다.

## UUID는 항상 전체 표기

UUID를 화면에 보여주거나 문서(태스크, 위키, PR 등)에 쓸 때는 반드시 축약하지 않고 **전체**를 그대로 쓴다.

- ❌ `6c20...de8a`
- ✅ `6c202fd4-e4aa-434f-a5c8-07f9c413de8a`

축약 UUID는 후속 조회·복붙에 쓸 수 없으므로 정보 손실이다.
